# Generated corpus (JSONL)

Output mặc định gợi ý cho script mở rộng:

- `telex_sample.jsonl` — mẫu từ `scripts/expand_corpus.py` + `corpus/sources/sample_words.txt`.

Chạy wordfreq lớn nên ghi ra đây (ví dụ `telex_wordfreq.jsonl`, `vni_wordfreq.jsonl`) để giữ `corpus/` gọn. `cbakey_corpus_test` quét **đệ quy** mọi `*.jsonl` dưới `corpus/`.
